# 部署指南

## 环境

| 项 | 要求 |
|---|---|
| 系统 | Linux（Debian / Ubuntu 推荐） |
| Python | **3.10+**，零第三方依赖 |
| 端口 | 默认 **17613**，需放行入站 |
| 磁盘 | SQLite + 安装包（每个约 350KB） |

## 一、上传并启动

```bash
SERVER=root@你的服务器 ./deploy/deploy.sh
```

或手动：

```bash
ssh root@你的服务器 'mkdir -p /opt/wishpool/pkg /opt/wishpool/backups'
scp server/wish_server.py server/panel.html root@你的服务器:/opt/wishpool/
scp deploy/wishpool.service root@你的服务器:/etc/systemd/system/
ssh root@你的服务器 'systemctl daemon-reload && systemctl enable --now wishpool'
```

验证：

```bash
curl http://127.0.0.1:17613/healthz
# {"ok":true,...}
```

首次启动会在 `DB_PATH` 同目录生成 `admin_pass.txt`（权限 600），
面板「管理」登录用它。改密码：

```bash
echo '新密码' > /opt/wishpool/admin_pass.txt && systemctl restart wishpool
```

## 二、配置

全部通过环境变量（见 `deploy/wishpool.service`）：

| 变量 | 默认 | 说明 |
|---|---|---|
| `PORT` | `17613` | 监听端口，支持 `17613,8080` 多端口 |
| `HOST` | `0.0.0.0` | 监听地址 |
| `DB_PATH` | `<脚本目录>/wish.db` | SQLite 路径 |
| `LOG_PATH` | `<脚本目录>/wish.log` | 日志 |
| `PANEL_PATH` | `<脚本目录>/panel.html` | 面板 |
| `PKG_DIR` | `<脚本目录>/pkg` | 安装包目录 |
| `ADMIN_PASS` | 空 | 管理密码；为空则用 `admin_pass.txt` |
| `MAX_BODY` | `65536` | 普通请求体上限 |
| `RATE_SUBMIT` / `RATE_VOTE` / `RATE_CLAIM` | `20` / `240` / `60` | 每 IP 每 60s 限流 |

## 三、客户端指向

改 `client/src/services/api.js` 顶部：

```js
export var ENDPOINTS = [
  'http://你的服务器:17613'
]
```

需要局域网兜底就再追加一个地址——客户端按顺序探 `/healthz`，第一个通的会被记住。

然后打包：

```bash
cd client
npm install
npm run build:prod          # 产出 8001865309000101.x.y.z.amr
```

装机：

```bash
adb push 8001865309000101.x.y.z.amr /userdisk/
adb shell miniapp_cli install /userdisk/8001865309000101.x.y.z.amr
```

> 打包需要 `aiot-vue-cli`（`npm install` 会装好）与 `falcon-ui`。
> 本项目的界面全部用原生标签 + 自有样式，没有额外 UI 库依赖。

## 四、发版（自动更新）

1. 面板 → 管理 → **发布更新**
2. 上传新 `.amr`（或从已有包中选择）
3. 填版本号、更新说明，可选「强制更新」
4. 点「发布」

客户端下次启动会 `GET /app-update` 并弹窗；强制更新时弹窗不可跳过。

> **首次**必须手动安装一次带 `libs/libjsapi_updater.so` 的包；
> 之后才能自动下载安装（旧版本没有原生安装能力）。

## 五、Nginx 反代（可选）

```nginx
server {
    listen 80;
    server_name 你的域名;

    client_max_body_size 32m;          # 安装包上传

    location / {
        proxy_pass http://127.0.0.1:17613;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_buffering off;           # SSE 必须关缓冲
        proxy_read_timeout 3600s;
    }
}
```

想隐藏管理入口，可给 `/api/admin/` 单独加 IP 白名单。

## 六、备份

数据都在 SQLite 里，直接备份这个文件即可（含 WAL 时用 SQLite 在线备份）：

```bash
sqlite3 /opt/wishpool/wish.db ".backup /opt/wishpool/backups/wish-$(date +%F).db"
```

清空数据（保留结构）：

```bash
cd /opt/wishpool && sqlite3 wish.db \
  'DELETE FROM votes; DELETE FROM claims; DELETE FROM wishes; DELETE FROM client_logs;'
```

## 七、排错

| 现象 | 排查 |
|---|---|
| 笔端显示离线 | 笔上点「日志」看诊断，或面板后台 `GET /api/admin/logs?sn=` |
| 面板实时不更新 | 检查 Nginx 是否关了 `proxy_buffering`；浏览器是否被代理拦截 SSE |
| 认领报 401 | 管理密码不一致（笔端会缓存，改密后需在笔上重新输入） |
| 更新下载失败 | 检查服务器 `/pkg` 可访问；笔端路径必须是纯 ASCII |
